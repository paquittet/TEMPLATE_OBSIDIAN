The plugin `Git` allows to automatically push the content of the vault on your Github account to regularly save your vault and not have to think about loosing it.  

<br>

# Configuration 
1. Download `Git`
2. Add the pathway to `git.exe` in *Custom Git binary path* in the `Git` plugin parameters

> [!danger]
> If you are on Windows, `Program file` has to be replaced by `PROGRA~1` (e.g. `C:\PROGRA~1\Git\cmd\git.exe`) otherwise the blank space will cause a problem

<br>

3. Create a Github repository that will contain your vault
4. Clone your repository in your computer 
5. Paste all the content of the current vault in the newly created cloned repository
6. *Open folder as vault* the folder just cloned (see picture)

![[Pasted image 20251006170100.png]]

<br>

7. If everything worked, when you go to `Git` plugin parameters, you should see the option *Auto commit-and-sync interval* which allow you to configure the interval of **automatic** push of your vault on your Github

![[Pasted image 20251006170249.png]]   

<br>

It's done ! Now your vault will be automatically saved every x minutes and be accessible from wherever.
