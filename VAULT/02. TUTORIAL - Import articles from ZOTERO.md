# CITE ARTICLE IN NOTES

The package `Pandoc Reference List` and `Citations` allows you to cite any article you have in your Zotero library directly in your Obsidian. 

<br>


## Configuration  

1. Download `pandoc`
2.  Paste the link to `pandox.exe` in the *Fallback path to Pandoc* in `Pando Reference List` parameters
3. Go to your Zotero > File > Export library > select `Better CSL JSON` format and click on the "Keep updated" button
4.  This will create a `.json` file updated with any document you add in your Zotero library. Save this document in your vault. Copy the path to the `.json` file in the *Path to bibliography file* in in `Pando Reference List` parameters

<br>

## Utilisation
In order to cite directly in the text, you have to use the `@` following by the Zotero citekey (if you write at least one letter after the `@`, you'll have proposition of article among those present in your library). For the reference to appear as such, you need to be in reader mode.  Once cite, if you pass the mouse on the text references see what happens...  

> [!example]
> This work cite the work of @teplitskyBergmannsRuleClimate2008. You can also directly cite between bracket using `[@]` [@teplitskyBergmannsRuleClimate2008]. 

<br>


# STEPS TO IMPORT AN ARTICLE
* Access the command palette with `CTRL + p` (in Windows) 
* Search for "Zotero Integration : CREATE A READING SHEET (ARTICLE)" and click

> [!info]
> Zotero needs to be open in order for this to work.

* Write in the toolbar the name of the article you want to find in your library (can be the DOI, the title, the citekey...) (sometimes, the toolbar can be hidden, you have to find it by clicking on the Zotero icon in your research bar)
* Click Enter
